# Marathon Voice Comms

A Stream Deck plugin for [Marathon](https://www.marathonthegame.com) that puts
push-to-talk, mic mute, and team mute (deafen) on dedicated keys. Built for
Windows, dev-friendly on macOS.

> Status: early WIP. Marathon hasn't published official voice-chat keybinds
> yet, so the plugin sends whatever key you configure — bind the matching key
> in the game's audio settings.

## What it does

Three actions, each sending a configurable Windows keystroke into the
foreground window:

| Action       | Trigger                          | Behavior                                                |
|--------------|----------------------------------|---------------------------------------------------------|
| Push To Talk | Stream Deck button held          | Key **down** on press, **up** on release. Live state lights up cyan. |
| Mute Mic     | Stream Deck button tapped        | Single key tap, toggles a local on/off state.           |
| Mute Others  | Stream Deck button tapped        | Single key tap, toggles a local on/off state (deafen).  |

Each action's key is configured per-button in the Property Inspector. Defaults:
`v`, `m`, `n`. Modifier chords supported: `ctrl+shift+v`, `alt+f13`, etc.

## How it sends keys (Windows only)

Stream Deck plugins run on Node.js. There's no portable Node API for synthetic
keystrokes, and most native modules are awkward to build cross-platform when
the dev box is macOS and the target is Windows.

Solution: a persistent PowerShell helper
([`com.jossy.marathon.sdPlugin/helper/sender.ps1`](com.jossy.marathon.sdPlugin/helper/sender.ps1))
that the plugin spawns once on startup. Commands are JSON-over-stdin
(`{"op":"down","key":"ctrl+m"}`). The helper resolves the combo to virtual key
codes and dispatches via the Win32 `SendInput` API.

On macOS the spawn is skipped (`process.platform !== "win32"`), so keystroke
calls are silent no-ops. Plugin loads, buttons render, state toggles work —
you just can't drive a Windows game from a Mac (obviously).

## Skin

Marathon's Runner palette: `#FF4E14` (Runner Orange) on `#0A0807` (deep black),
with `#22E1FF` cyan accents for "live transmit" indicators. Buttons are framed
with the HUD corner-brackets the game uses throughout its UI. Muted states use
a red slash overlay on a dimmed glyph.

## Install (Windows, end-user)

1. Download the latest `.streamDeckPlugin` from Releases (when published) and
   double-click to install.
2. In Marathon → Settings → Audio, bind:
   - Push-to-Talk → `v` (or whatever you put in the Stream Deck PI)
   - Mute Self → `m`
   - Mute Team → `n`
3. Drag the three actions onto your Stream Deck.

## Install (dev, from source)

Requires Node 24 and the Stream Deck app.

```sh
npm install
npm run build
npx streamdeck link ./com.jossy.marathon.sdPlugin
npx streamdeck restart com.jossy.marathon
```

For watch mode (auto-rebuild + restart on save):

```sh
npm run watch
```

To validate the manifest:

```sh
npx streamdeck validate ./com.jossy.marathon.sdPlugin
```

## Layout

```
src/
  plugin.ts                    # entry point, action registration
  keysender.ts                 # spawns PowerShell helper, sends JSON commands
  actions/
    push-to-talk.ts            # hold-to-talk, key down/up
    mute-mic.ts                # toggle, key tap
    mute-others.ts             # toggle, key tap (deafen)
com.jossy.marathon.sdPlugin/
  manifest.json                # Stream Deck manifest
  helper/sender.ps1            # Win32 SendInput via P/Invoke
  imgs/                        # SVG action icons + PNG marketplace tile
  ui/                          # Property Inspector HTML per action
  profiles/                    # bundled .streamDeckProfile slots (see README in there)
  bin/                         # rollup output (gitignored)
  logs/                        # runtime logs (gitignored)
```

## Bundled profile (default layout)

The [`com.jossy.marathon.sdPlugin/profiles/`](com.jossy.marathon.sdPlugin/profiles/)
directory is ready to receive an exported `.streamDeckProfile` and a matching
`manifest.json` entry. See the README in that directory for the export
workflow. Stream Deck profile files are an opaque format Elgato treats as an
app-export artifact, so they have to be generated by configuring the layout
once in the Stream Deck app and exporting it.

## Limitations / things to know

- **Mute state can drift.** The mute toggles track local state, not the game's.
  If you mute via the in-game menu, the button's lit/dim state can desync; tap
  it once to resync. Reading actual game state would require a memory hook or
  a game-side API, neither of which Marathon exposes.
- **Marathon keybind defaults are unknown.** Defaults in the plugin are
  guesses (`v`, `m`, `n`); set them yourself.
- **Windows-only for keystroke delivery.** macOS/Linux loads the plugin but
  no-ops the keysender.

## Releases

Tag-driven. Pushing a `v*.*.*` tag triggers
[`.github/workflows/release.yml`](.github/workflows/release.yml), which builds,
packs a `.streamDeckPlugin` file, and attaches it to an auto-generated GitHub
Release.

```sh
# bump manifest Version in com.jossy.marathon.sdPlugin/manifest.json first,
# then:
git tag v0.1.1
git push origin v0.1.1
```

The workflow translates `v0.1.1` to the Stream Deck 4-part manifest version
`0.1.1.0` and packs against it.

Every push/PR to `main` runs [`.github/workflows/build.yml`](.github/workflows/build.yml)
which builds and validates the manifest — no packing.
